# AI-Powered WMS (Warehouse Management System)

## Overview

This project is a modern, scalable **Warehouse Management System (WMS)** built using **HTML, CSS, and JavaScript**. It is designed to reduce operational friction in logistics, improve shipment visibility, and enhance customer experience through **automation and AI-powered features**, including voice interaction via ElevenLabs.

The system focuses on simplicity, usability, and extensibility, making it suitable for both startups and enterprise-level logistics platforms.

## Design Goals

* Reduce friction in shipment and warehouse management workflows
* Improve visibility and transparency across delivery operations
* Enhance customer experience through AI-driven automation
* Simplify logistics operations with an intuitive user interface
* Provide a scalable design system for future growth

## Key Features

* Shipment tracking and status management
* Inventory and warehouse visualization
* Order processing and logistics workflows
* Real-time updates and operational insights
* Voice interaction powered by ElevenLabs
* Modular and scalable frontend architecture
* Clean and responsive UI/UX

## Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling and layout
* **JavaScript (Vanilla)** – Application logic
* **ElevenLabs API** – Voice interaction and AI audio features

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/ai-wms.git
```

### 2. Open the Project

Simply open `index.html` in your browser.

## ElevenLabs Integration (Voice Feature)

To enable voice functionality:

1. Sign up at ElevenLabs
2. Get your API key
3. Integrate it into your JavaScript logic

Example:

```javascript
const apiKey = "YOUR_API_KEY";
```

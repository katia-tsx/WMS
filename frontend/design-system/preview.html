Color

Neutral grays, a single brand hue, and semantic success/warning/danger/info scales. Components consume semantic aliases (--color-primary, --color-danger-subtle …), never the raw scale, so retheming means editing tokens.css only.

Neutral

Brand

Semantic

Spacing

8pt grid with a 4px half-step for dense, data-heavy screens. Tokens run --space-0 through --space-32.

Typography

Inter (variable font) with a system-sans fallback stack, plus a monospace token for tabular SKU/quantity data. Body defaults to 14px to match dense SaaS dashboards.

Border radius

Elevation

Shadow tokens for card layering. In dark mode these automatically swap to a hairline-border strategy since dark shadows don't read well on dark surfaces.
